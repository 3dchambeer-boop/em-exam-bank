# المصادر

حط هنا **نفس الملفات اللي ترفعها على NotebookLM**، كل مادة بمجلد (مثلاً `engineering-management/`).

## شلون ترفع من الموبايل
1. افتح المستودع بـ GitHub ← ادخل المجلد ← **Add file ← Upload files**.
2. ارفع الملف واضغط **Commit changes**.
3. كول لـ Claude: "انضاف مصدر جديد، حلله".

## ملخصات NotebookLM
اذا NotebookLM طلعلك ملخص أو FAQ أو Briefing Doc: انسخه، وسوي ملف جديد بالمجلد (**Add file ← Create new file**) باسم مثل `notebooklm-ch5-summary.md` والصقه بيه.
